# Handwritten-Drawing-Recognition-Game
A mini game where users draw simple shapes or letters using the mouse, and the program guesses the drawing using basic pattern matching.
A Java Swing based desktop application that allows users
to draw letters and numbers using the mouse and attempts
to recognize the submitted character.
Technologies:
- Java
- Java Swing
- Maven
- NetBeans
- GitHub
